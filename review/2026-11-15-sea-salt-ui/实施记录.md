# 鲸鱼 0.8 · 海盐蓝 UI 重构

日期：2026-11-15

## 范围

- 首页保留每日一句、今日信息和六个内容入口。
- 天气缩为包含在今日信息行内的小字。
- 六个入口改为 2×3 平面卡片，保留原有频道顺序、真实摘要和无障碍标识。
- 发现页保持现有标题、频道选择、子筛选和资讯列表结构，只跟随全局颜色变化。
- 全局主题由深绿/青绿改为海盐蓝；深色模式使用中性炭黑。
- 增加轻量按压缩放，并遵守 Reduce Motion。
- Agent 处理状态改为清晰的“正在研究/正在执行 + 当前动作”状态块，不展示私有思维链。
- 底部主 Tab 改为淡入切换，不再与频道横滑、阅读滚动和左缘返回争夺手势。
- 版本号更新为 `0.8.0 (140)`。

## 保持不变

- DeepSeek 请求、工具路由、确认、权限、记忆和声音逻辑。
- 每日一句、天气、待办、六个频道入口的功能行为。
- 发现页布局和已完成的国内/国际、Steam 折扣调整。
- 现有 UI 自动化标识。

## 验证

- 后端 Node 测试：90 项通过。
- `git diff --check`：通过。
- iOS 编译、UI 测试、模拟器截图和 IPA 由 GitHub Actions 完成。
