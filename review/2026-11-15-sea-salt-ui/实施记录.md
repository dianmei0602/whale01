# 鲸鱼 0.8 · 海盐蓝 UI 与讯飞朗读

日期：2026-11-15

## 范围

- 首页保留每日一句、今日信息和六个内容入口。
- 天气缩为包含在今日信息行内的小字。
- 六个入口改为 2×3 平面卡片，保留原有频道顺序、真实摘要和无障碍标识。
- 发现页保持现有标题、频道选择、子筛选和资讯列表结构，只跟随全局颜色变化。
- 全局主题由深绿/青绿改为海盐蓝；深色模式使用中性炭黑。
- 增加轻量按压缩放，并遵守 Reduce Motion。
- Agent 处理状态改为清晰的“正在研究/正在执行 + 当前动作”状态块，不展示私有思维链。
- 底部主 Tab 改为淡入切换，不再与频道横滑、阅读滚动和左缘返回争夺手势。
- 助手回复优先使用讯飞小露 `x4_yezi` 语音合成，失败时回退系统中文朗读。
- “语音回应”开启时自动朗读助手最终回复；消息旁的喇叭按钮也可手动朗读或停止。
- 讯飞凭据可从本机 Keychain 或构建环境读取，不写入源码。
- 设置页可保存、删除讯飞密钥，并直接试听小露 `x4_yezi`。
- 版本号更新为 `0.8.1`，安装构建号为 `141.1`。
