# 金句语料库（1440 条 · 30 天不重复）

鲸鱼首页顶部「至理名言 / 名人名句」的正式语料。本目录同时保存审核页与生成脚本，App 里的语料由这里离线生成。

## 规模与构成

- 总量：**1440 条** = 6 个主题 × 240 条
- 主题：修身自省、处世智慧、心境审美、读书学习、励志进取、家国天下
- 批次：v1 480 条（001–080）+ 扩充 960 条（081–240）
- 长度：去标点后 6–30 字，平均 11.8 字
- 编号：`XS` `CS` `XJ` `DX` `LZ` `GJ` 各 001–240

## 为什么是 1440 条

首页每 30 分钟换一条金句，一天 48 条。要满足「30 天不重复」，必须有：

```
48 条/天 × 30 天 = 1440 条
```

480 条只够 10 天，这是 0.7.16 的缺口。本轮补齐到 1440 条，并把
`DailyQuote.poolCycleHours` 从 240 改为 720，循环周期与语料规模对齐。

步长 37 与 1440 互质（1440 = 2^5 × 3^2 × 5，37 为质数），因此任意连续
1440 个半小时时段恰好覆盖整池，不会在中途重复。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 审核页，数据已内嵌，双击即可离线使用 |
| `quotes.tsv` | 纯文本源，6 列：编号 / 主题 / 正文 / 出处 / 篇章 / 语气 |
| `quotes.sample.json` | 结构化正式语料，含 `status` 字段 |
| `quotes.v1-480.json` | v1 480 条快照，合并脚本以它为基准，勿改 |
| `_expansion.json` | 扩充池（每主题 160 条 + 备用池），`[正文, 出处, 篇章, 语气]` |
| `_corpus.pipe` | 编辑用中间源（`\|` 分隔） |
| `_merge.mjs` | 合并 v1 与扩充池，生成 1440 条正式语料 |
| `_build.py` | 校验并重新生成 TSV / JSON / HTML（需 Python） |

### 重新生成流程

```powershell
# 1. 合并语料（Node，无需 Python）
node review/2026-11-14-quote-corpus-v1/_merge.mjs

# 2. 生成 Swift 离线语料
node tools/generate_daily_quote.mjs
```

两条脚本都会校验：总数 1440、每主题 240、编号唯一且前缀匹配、正文去重、字段无空值。
任何一项不通过会直接报错，不会覆盖产物。

## 审核方式

双击 `index.html`：

- 可按主题、状态、**出处**筛选；支持正文、出处、编号搜索
- `←` `→` 上一条 / 下一条；`1` 通过；`2` 淘汰；`0` 待定；`E` 编辑
- 每条可改正文、出处、篇章、语气，修改与状态自动存 `localStorage`
- 「导出已通过」得到 `quotes.approved.json`；「导出全部」得到 `quotes.reviewed.json`

审核状态只存在浏览器本机，换浏览器或清缓存会丢失，重要结果请及时导出 JSON。

## 选句口径

1. 语义完整，不截对话碎片，不用生僻字堆砌
2. 简体中文，统一使用通行标点
3. 出处到书名，篇章到具体篇目；诗人作品标作者 + 篇名
4. 全局唯一，仅标点不同视为重复
5. 避开消极厚黑、低俗、误归属、明显鸡汤化改写
6. 语气标签控制在 2–4 字，便于首页排版

扩充批次延续同一口径：只收有明确出处的成句，不把成语、后人概括或
现代鸡汤包装成古文。

## 已知需人工确认的条目

- `GJ-012`「天下兴亡，匹夫有责」：顾炎武原文为「保天下者，匹夫之贱与有责焉耳矣」，
  八字为后人有名概括。扩充池里另收了顾炎武原文，两条并存，可按需二选一
- `CS-038`「十年树木，百年树人」：由《管子·权修》「终身之计，莫如树人」等句概括而成
- `CS-033`「鹬蚌相争，渔翁得利」：为《战国策·燕策二》寓言形成的成语，非原文成句
- `XS-001`「吾日三省吾身：为人谋而不忠乎？」：取原句第一问，保留冒号，语义自足
- 明清小品（《菜根谭》《小窗幽记》《围炉夜话》《幽梦影》）以通行本文字为准，
  不同版本略有出入，接入前建议按选定版本复核
- 扩充批次中的《尚书》类条目（如「万方有罪，在予一人」）按通行《十三经注疏》本标篇目
