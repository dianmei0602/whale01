## 文件

| 文件 | 用途 |

| `index.html` | 审核页，数据已内嵌，双击即可离线使用 |

修改内容后在本目录执行：

```powershell
python _build.py
```

脚本会校验：总数 480、每主题 80、编号唯一且前缀匹配、正文去重、字段无空值。任何一项不通过会直接报错，不会覆盖产物。

## 审核方式

双击 `index.html`：

- 可按主题、状态、**出处**筛选；支持正文、出处、编号搜索
- `←` `→` 上一条 / 下一条；`1` 通过；`2` 淘汰；`0` 待定；`E` 编辑
- 每条可改正文、出处、篇章、语气，修改与状态自动存 `localStorage`
- 「导出已通过」得到 `quotes.approved.json`；「导出全部」得到 `quotes.reviewed.json`
- 「重置」清空本机审核记录

审核状态只存在浏览器本机，换浏览器或清缓存会丢失，重要结果请及时导出 JSON。

建议先按「出处」把《传习录》《菜根谭》《小窗幽记》《围炉夜话》《幽梦影》《诗经》逐本过一遍，再随机抽查唐诗宋词。

## 选句口径

1. 语义完整，不截对话碎片，不用生僻字堆砌
2. 简体中文，统一使用通行标点
3. 出处到书名，篇章到具体篇目；诗人作品标作者 + 篇名
4. 全局唯一，仅标点不同视为重复
5. 避开消极厚黑、低俗、误归属、明显鸡汤化改写
6. 语气标签控制在 2–4 字，便于首页排版

## 已知需人工确认的条目

- `GJ-012`「天下兴亡，匹夫有责」：顾炎武原文为「保天下者，匹夫之贱与有责焉耳矣」，八字为后人有名概括，出处标《日知录·正始》
- `CS-038`「十年树木，百年树人」：由《管子·权修》「终身之计，莫如树人」等句概括而成
- `CS-033`「鹬蚌相争，渔翁得利」：为《战国策·燕策二》寓言形成的成语，非原文成句
- `XS-001`「吾日三省吾身：为人谋而不忠乎？」：取原句第一问，保留冒号，语义自足
- `XS-037`「主忠信，无友不如己者，过则勿惮改」：保留原句前置分句，避免五字孤句
- B 批《传习录》标为「卷上 / 卷下」，不同版本分卷略有差异，接入前建议按选定版本复核
- B 批《菜根谭》《小窗幽记》《围炉夜话》《幽梦影》以作者朝代定位，未强分门类，避免编造篇目
- `DX-077`「学而不已，阖棺乃止」：出自《韩诗外传》，亦见《孔子家语》，以《韩诗外传》为准
- `CS-063`「眼里无点灰尘，方可读书千卷」、`CS-064`「交友之先宜察，交友之后宜信」：明清小品版本文字略有出入
