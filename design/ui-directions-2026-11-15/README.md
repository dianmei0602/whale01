# 华章 UI 方向比较

日期：2026-11-15

四个方案共用现有编年史资料，不改变数据模型。比较重点是首屏回答的问题，而不是配色。

| 方案 | 首屏问题 | 最合适的位置 |
| --- | --- | --- |
| 长河 | 这一年同时存在哪些政权？ | 主界面与时间浏览 |
| 册页 | 这个时代最值得先读什么？ | 朝代详情与事件阅读 |
| 天下 | 政权之间如何并存与接替？ | 专题比较视图 |
| 夜读 | 这段历史究竟发生了什么？ | 深色主题与长文阅读 |

## 推荐组合

以“长河”为主壳，让时间关系成为产品身份。朝代和事件详情采用“册页”的出版式层级；把“天下”作为可切换的并立政权视图；“夜读”跟随系统深色模式启用。

## 阅读顺序

1. 先用“长河”建立整体时间感。
2. 点击具体年代或事件，进入“册页”式详情。
3. 需要比较多个政权时，切换“天下”。
4. 长时间阅读时，进入“夜读”模式。

## 设计原则

- 并存政权必须是正面信息，不能藏在二级筛选里。
- “约”“通行纪年”“存在异说”是内容状态，不使用统一的警告色。
- 时间轴中的颜色只表示政权或选中状态，不承担“好/坏”含义。
- 详情页先给事件标题和年份，再给解释与出处。
- iPhone 上保持单手可达的底部导航，主要操作位于拇指区。

## 实施顺序

1. 将现有总览与时间轴合并为“长河”首页。
2. 用“册页”重排政权详情和事件详情。
3. 增加“天下”并立政权视图。
4. 增加深色模式并套用“夜读”排版。
