# Nomi 执行清单

> 详细验收标准、依赖和验证方法见 [plan.md](plan.md)。一次只推进一项 Task，未通过 Checkpoint 不进入下一阶段。

## Phase 0：安全止损

- [ ] Task 1：撤销并清理讯飞密钥，测试脚本改用环境变量
- [ ] Task 2：摄像头默认关闭、权限按场景申请、修正隐私说明

### Checkpoint A

- [ ] 无真实密钥进入仓库
- [ ] 摄像头默认关闭
- [ ] 隐私说明与代码一致
- [ ] 未确认时不会修改用户数据

## Phase 1：动作安全与测试底座

- [ ] Task 3：增加 XCTest target，CI 执行测试
- [ ] Task 4：修复会议匹配，加入取消/改期确认
- [ ] Task 5：统一动作预览、执行、回执和审计日志

### Checkpoint B

- [ ] 测试全部通过
- [ ] 破坏性动作必须确认
- [ ] 找不到目标时只追问
- [ ] 重复点击不会重复执行

## Phase 2：拆分 Agent 内核

- [ ] Task 6：定义 Agent、工具协议和风险等级
- [ ] Task 7：迁移日历、天气、位置工具
- [ ] Task 8：建立 NomiAgent 和混合意图路由

### Checkpoint C

- [ ] AssistantView 只承担显示和交互
- [ ] 工具和策略可以独立测试
- [ ] 新增只读工具不需要修改主视图
- [ ] 高风险操作无法绕过确认

## Phase 3：界面收敛和结果表达

- [ ] Task 9：收敛为 Nomi、今日两个主入口
- [ ] Task 10：Nomi 首页改为任务画布和状态反馈
- [ ] Task 11：Dynamic Type、VoiceOver、数据状态和对比度

### Checkpoint D

- [ ] 一级入口不超过两个
- [ ] 一次任务可在一个主入口完成
- [ ] 结果显示来源、时间和成功状态
- [ ] iPhone SE 与 iPhone 16 Pro 截图检查通过

## Phase 4：真实记忆和主动提醒

- [ ] Task 12：拆分聊天记录和长期记忆
- [ ] Task 13：建立模型上下文组装器
- [ ] Task 14：统一通知预算、去重、降频和动作

### Checkpoint E

- [ ] 记忆可查看、编辑和删除
- [ ] 通知默认每天不超过 3 条
- [ ] 模型上下文可解释
- [ ] 主动提醒失败不影响核心功能

## Phase 5：后端接入

- [ ] Task 15：建立 NomiGateway，代理模型、语音和工具
- [ ] Task 16：客户端移除默认自带 Key 的使用模式

### Checkpoint F

- [ ] 普通用户无 Key 可用
- [ ] 客户端无长期服务端密钥
- [ ] 限额、熔断和脱敏日志有效
- [ ] 后端故障时本地能力可用

## Phase 6：附近服务与预订

- [ ] Task 17：接入附近美食和酒店查询
- [ ] Task 18：预订预览和官方页面跳转
- [ ] Task 19：为正式预订接口预留状态机

### Checkpoint G

- [ ] 一句话可以查到酒店/餐厅/票务结果
- [ ] 结果有来源和时间
- [ ] 无未确认预订或支付
- [ ] 失败场景可恢复

## Phase 7：真机验收与发布

- [ ] Task 20：建立至少 60 条中文指令回归集
- [ ] Task 21：真机连续使用 14 天并记录指标
- [ ] Task 22：完成隐私、权限、后台行为和诊断检查

### Checkpoint H：1.0 Alpha

- [ ] Critical 安全问题清零
- [ ] 高风险动作全部确认
- [ ] 普通用户无需填写 API Key
- [ ] 14 天真机验证通过
- [ ] 最常用 5 个任务成功率达到 85% 以上
