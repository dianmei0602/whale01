# Nomi 情报中心执行计划

## 目标

在保持三个主入口不变的前提下，新增统一的「今天值得知道」信息中心：

- 要闻
- 市场
- 热搜
- AI

## 架构决策

- 新入口放在对话页现有快捷动作中，不增加底部 Tab。
- 四个模块并发加载、独立失败；单个数据源失败不阻断其他模块。
- 股票先做指数、自选股、名称搜索和只读行情，不做交易和投资建议。
- 微博只展示热搜标题、排名和热度，详情在 Nomi 内打开。
- 所有外部数据必须显示来源、更新时间和降级状态。
- 处理结果由统一的 `IntelligenceDigest` 传给首页卡片、详情页和对话。

- [x] Task 1：定义情报模型、股票与微博解析器，并补纯逻辑测试。
- [x] Task 2：实现多源中文新闻、股票行情、微博热搜服务和统一聚合服务。
- [x] Task 3：实现首页简报卡与四模块详情页。
- [x] Task 4：实现股票搜索、添加、删除自选和行情刷新。
- [x] Task 5：补聊天意图、快捷建议、内嵌网页和局部失败提示。
- [x] Task 6：版本升级、文档更新、本地全量验证。

## 验收

- [x] 三个主入口数量不变。
- [x] 新闻、股票和微博都可以真实加载，失败时不显示假数据。
- [x] 股票名称可以搜索并加入自选，最多 8 只。
- [x] 指数和自选股显示价格、涨跌额、涨跌幅与延迟提示。
- [x] 微博热搜前 20 条可查看，并在 Nomi 内打开相关页面。
- [x] 首页只显示一条信息简报，不形成资讯看板。
- [x] 本地 Swift 语法检查和全部逻辑回归通过。

## 风险

- 股票与微博接口属于公网数据源，未来可能限流或改结构，必须保留可见降级。
- 当前 Windows 无法编译 SwiftUI，最终编译验证仍需 GitHub Actions；未收到推送命令前不触发。
- 免费签名与 App Store 上架前仍需确认数据授权和平台条款。
