## Build 13 · 天气降级

- 网络断开、请求超时和天气服务失败分别显示原因。
- 没有定位时明确显示正在使用的设置城市；天气成功时仍可正常展示。
- 定位为“未询问”时提供“允许定位”，为“已关闭”时提供“去系统设置”。
- 首页天气入口不再自动发消息，而是打开天气状态页。
- 天气失败不会阻塞日程、待办和对话，并提供“用设置城市重试”。

## 目标

Build 11 已具备六类信息和游戏详情，但首页入口过多，真实日程与待办被推到下方；资讯页打开一个板块时需要等待所有数据源；子页返回、字号和触控目标也不统一。

本版只调整产品层级、交互规则和加载方式，不新增数据供应商，不改变钛合金 Nomi 本体。

## 1. 首页

- 首页顺序改为：品牌与播放状态 → Nomi 与每日一句 → 下一件事 → 六个紧凑发现入口 → 天气/音乐/位置 → 日程与待办。
- Nomi 主卡高度由约 238pt 压缩到 184pt。
- 删除与六个资讯入口重复的“今天值得知道”快捷卡。
- 六个资讯入口改为 2×3 紧凑按钮，触控高度 44pt。
- 下一件事优先显示逾期待办，其次在最近日程和近期待办中选择更早的一项。
- 点击下一件事会带着明确的准备提示进入对话。
- 当前入口再次点击：对话返回首页、待办回到顶部、设置返回根页。
- 首页输入框获得焦点后直接进入对话态，不再在首页内容上弹出键盘。

## 2. 导航与手势

- 主入口横滑仅在三个根页面生效。
- 设置进入子页后暂停主入口横滑，优先使用系统返回手势。
- 设置根页改用值驱动的 `NavigationPath`，支持回到根页。
- 资讯、股票、游戏和黑胶页支持从屏幕左边缘右滑关闭。
- 网页阅读器保留网页自身前进/后退手势，不抢浏览器历史。
- 资讯页外部链接图标改为应用内进入箭头。

## 3. 字号与触控

- UI 固定字号统一接入 `Font.nomiScaled`，跟随系统 Dynamic Type。
- 正文文字以 11.5pt 为显示下限，并按系统字号缩放。
- 主要关闭、发送、语音、筛选和头部按钮扩大到 44pt 触控目标。
- 黑胶页删除无动作的省略号，进度条触摸高度提高到 32pt。

## 4. 资讯加载

- 资讯中心不再一次等待新闻、时事、行情、微博、知乎和游戏全部返回。
- 首次进入只加载当前板块；切换到其他板块时再按需加载。
- 每个板块保留缓存；刷新失败时继续显示上次内容并标明失败。
- 六个板块全部支持下拉刷新。
- 顶部板块导航改为横向滚动文字与统一青色下划线。
- 行情前台轮询从 30 秒调整为 60 秒，后台停止。
- 资讯列表移除顶部重复介绍块，内容更早出现。

## 5. 待办与结算语义

- 系统日历会议不再计入待办完成率。
- “已完成”只统计提醒事项中真正完成的待办。
- 会议使用“进行中”“待安排”“已结束”三种状态。
- 首页只显示可执行的待办标题、来源与状态。
- 新建待办改为大表单，创建按钮固定在安全区底部，键盘出现时仍可触达。

## 6. 视觉整理

- 移除首页与发布版本中的 `BETA` 标记。
- 移除共享卡片、输入栏和底栏的重复毛玻璃层，减少滚动时的合成开销。
- 资讯模块选择、文章圆点和卡片重点统一使用一个主强调色；红色和绿色只表达行情涨跌等状态。
- 股票指标改为一个分组面板，减少小卡片堆叠。
