# Nomi 1.6 · B 方案首页整合

日期：2026-11-15  
目标版本：`1.6 (20)`  
状态：SwiftUI 实现完成并推送；本地验证通过，GitHub Actions 被账户计费限制阻断

## 本次调整

- 底部主导航改为“对话 / 值得知道 / 待办”。
- 设置从底部导航移到首页页眉最右侧。
- 设置页仍是独立主页面，增加右上角关闭入口返回首页。
- 首页中段新增“值得知道”摘要卡，显示真实缓存中的时事、AI、行情和更新时间。
- 首页日程与待办改为左右双栏：
  - 左侧：今天的流向，最多三条。
  - 右侧：紧凑待办栏，可直接完成或打开全部待办。
- 首页保留每日古籍作为第一阅读焦点。
- 微博、知乎、游戏等资讯仍位于完整的“今天值得知道”页面。

## 交互

- 点“值得知道”中的分类会直接打开对应资讯模块。
- 点日程会把“帮我准备…”填入对话。
- 点待办圆圈会写回系统提醒事项；写失败不伪装完成。
- 主页面左右滑动顺序为：对话 → 值得知道 → 待办。
- 设置页不参与横向主页面手势，使用右上角关闭按钮返回首页。
