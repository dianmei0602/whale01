## 明天第一件事：调通语音

### 现状

讯飞在线合成**代码已完成**，并且我用真实密钥在 Windows 上**实测通过**：

```
✅ xiaoyan    37,584 字节 mp3

✅ aisjiuxu   43,848 字节 mp3（男声）
❌ x4_yeting  licc failed（账号没授权这个音色）
```

### 关键：鉴权方案（踩过的坑）

**必须用 `Authorization` 头，不能拼在 query 里。**

```
Authorization: api_key="7d47e6d2...", algorithm="hmac-sha256",
               headers="host date request-line", signature="<base64 HMAC-SHA256>"
Date: Sat, 07 Nov 2026 20:45:12 GMT
```

早期文档那套 `wss://...?authorization=xxx&date=yyy&host=zzz` 现在返回：
```
401 {"message":"HMAC signature cannot be verified:enforced header 'host' not used for signature creation"}
```

签名原文：`host: tts-api.xfyun.cn\ndate: <同一个 date>\nGET /v2/tts HTTP/1.1`
**签名和 Date 头必须用同一个时间字符串**（分两次取会跨秒对不上）。

### 上机验证三步

1. 设置 → 讯飞语音 → **点「试听这句」**（不用说话就能验证）
   - 听到声音 → 链路通
   - 没声音 → 看 Xcode 控制台的 `讯飞合成失败: ...`
2. 设置 → 声音 → 打开「让它说话」
3. 点 Nomi → 说一句话 → 再点一下结束 → 看是否有回复 + 是否有声音

### 排查表

| 现象 | 原因 |
|---|---|
| 试听没反应 | 网络/鉴权；控制台有具体错误码 |
| 11200 licc failed | 该音色没授权，换 `xiaoyan` |
| 11201 | 当日免费额度用完（约 500 次） |

| 声音和文字对不上 | 合成是异步的，回答和语音可能错开；需要加播放队列 |
