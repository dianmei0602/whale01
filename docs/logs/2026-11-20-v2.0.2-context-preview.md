# 2.0.2 上下文、主任务与统一预览

- 日期：2026-11-20
- 版本：`2.0.2 (202.x)`
- 目标：减少重复解释、减少首页无效信息、统一所有写操作的心智模型

## 1. 当前任务上下文

- 新增 `AgentWorkingContext`，保存目标、状态、摘要、来源消息和更新时间。
- 上下文会跨页面与 App 重启保留，超过 24 小时自动失效。
- 助手页顶部显示当前任务；点按回到原对话，右侧关闭后不再占用首页。
- 新对话会主动清除旧上下文，避免“继续”误接上一件事。

## 2. 首页主任务

首页不再平均展示“接下来 / 需要你 / 继续”三行信息：

- 待确认或失败事项优先成为主任务。
- 否则继续当前未完成任务。
- 否则展示最近的真实日程或待办。
- 空状态压缩为一句启动提示，不再连续显示三个“没有”。
- 每日一句、今日判断和常用频道退居主任务之后。

主任务通过标题、状态、说明和一个明确动作组成，用户打开首页第一眼就知道下一步做什么。

## 3. 统一操作预览

新增共享 `OperationPreview` 与 `OperationPreviewCard`，统一显示：

- 将创建、将修改、将删除、将交接或将保存
- 操作对象
- 时间、项目、时长、影响等关键字段
- 系统写入说明
- 确认与取消

已经接入：

- 助手里的提醒、日程、偏好和删除操作
- 待办快速录入
- 助手回答转待办
- 补充待办时间
- 待确认操作卡片

可逆的单次勾选仍采用“立即执行 + 8 秒撤销”；不可逆或结构性修改统一先预览。

## 4. 深色主题调整

原深色主题接近纯黑，长时间使用对比过硬。2.0.2 改为分层石墨色：

### 海盐深夜

- 页面：`#1F292E`
- 卡片：`#2B373D`
- 输入框：`#2A353A`
- 顶栏／底栏：`#242E33`
- 主文字：`#F4F8FA`

### 夜海深夜

- 页面：`#22292B`
- 卡片：`#2D3436`
- 控制面板：`#364043`
- 主文字：`#FFF8E7`

### 鎏金深夜

- 页面：`#2A241B`
- 卡片：`#352F25`
- 控制面板：`#40392C`
- 主文字：`#FFF0C9`

近黑不再作为页面底色；夜间通过页面、卡片、控件和分隔线的四级明度建立层级，同时保留品牌色。

## 5. 验收重点

- 上下文经过重启仍存在，新对话会清除。
- 首页只显示一个主任务，空状态不占多行。
- 所有结构性写入都先进入相同预览。
- 三种配色在日间和夜间均能正常阅读。
- 深色模式不再使用近纯黑大底，并保持正文、按钮和次级信息可读。
