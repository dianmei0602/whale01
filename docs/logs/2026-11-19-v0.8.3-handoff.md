## 1. 这一阶段解决了什么

本轮不再把“有模型接口”当成完成，而是把一条可核对的链路做成：

`语音输入 → 讯飞听写 → DeepSeek 理解与规划 → Skill 选择 → 原生 Tool → 执行或确认 → 结果记录 → 小露朗读`

同时补齐了发现页阅读、游戏资讯中文化、A 股板块与快讯、任务记录回跳，以及可复现的 GitHub Actions 构建。

## 2. 关键实现

### 讯飞语音

- IAT 请求启用 `wpgs` 动态修订和 `rlang=zh-cn`。
- 修订结果按 `rg=[start,end]` 替换对应区间，不再误删后续语句。
- 静音结束阈值调整为 4 秒，最终识别等待延长到 7 秒。
- 使用真实凭据发送 4.95 秒中文语音，返回：
  “今天天气怎么样？帮我看看下午的安排。”
- TTS 音色保持小露 `x4_yezi`；讯飞失败时保留系统语音降级。

### 阅读与记录

- 助手长按直接朗读；菜单和无障碍操作也提供朗读。
- 发现页标题和摘要：轻点朗读，长按复制。
- “已复制”提示使用按压点窗口坐标，在手指上方显示，不随文章滚动。
- 新任务记录保存原消息 UUID。
- 旧记录按任务文字回退匹配历史用户消息。
- 记录跳转使用延迟二次滚动，避开弹层关闭与 LazyVStack 布局时序。
- 原对话被清空时显示明确说明，不再静默失败。

### 发现与行情

- 游戏资讯只保留国内中文媒体：游戏葡萄、游戏茶馆、触乐、游研社、IT之家·游戏、快科技·游戏。
- A 股新增板块分析、主力净流入排行与市场快讯。
- 个股详情新增相关新闻；没有匹配到个股时展示市场快讯，并明确票不对应个股利好。

### 构建与密钥

- 讯飞三项密钥只在构建时写入临时 App `Info.plist`。
- CI 日志只输出字段长度，不输出密钥。
- CI artifact 使用 AES 加密；本机用私钥解密。
- 打包后强制校验源码 SHA、三项讯飞字段、IPA 哈希和 Arm64 架构。
- 临时解密目录在验收后删除，临时部署 key 每次推送后撤销。

## 3. Agent 架构

| 层 | 当前实现 | 职责 |
| --- | --- | --- |
| 输入 | `VoiceInputController`、`ConversationComposerBar` | 麦克风、文字、照片与文件 |
| 语音识别 | `XfyunASRClient` | WebSocket 实时听写与动态修订 |
| 推理 | `LocalAgentEngine`、`AgentReasoningClient` | 目标拆解、风险判断、工具选择与回答审查 |
| 能力分组 | `AgentSkill`、`AgentSkillGuidance` | 12 组能力说明和允许工具 |
| 本机执行 | `NativeToolRouter` 与各 Executor | EventKit、HealthKit、MapKit、Speech、MusicKit 等 |
| 播放 | `SpeechPlaybackController` | 小露 TTS、系统语音降级、打断 |
| 结果 | `TaskRecord`、`OperationLedger` | 操作状态、幂等、恢复与 UI 记录 |

### 边界原则

- 模型不直接操作系统；只能提出工具调用。
- 写操作必须经过本地确认策略。
- 只有真实工具返回成功，才能说已经完成。
- 打开地图、网易云或消息编辑器只表示“已交接”。
- 新鲜资讯、行情、价格必须有来源与时间；数据缺失时不补写。

## 5. 经验

### 1. 真实配置会改变测试环境

构建时注入讯飞配置后，测试不能再假设“包内一定未配置”。测试要验证状态是否诚实，而不是验证某个开发机器恰好没有密钥。

### 2. 深链状态必须带稳定身份

只保存任务文字不足以精确跳转。新记录应保存消息 UUID；旧记录则需要按文字回退匹配，并为无法定位的情况提供解释。

### 3. UI 时序本身就是功能

关闭 sheet、切换页面、列表布局和 `ScrollViewReader` 滚动会在同一帧竞争。定位动作需要延迟并二次触发，不能只调用一次 `scrollTo`。

### 4. 反馈要靠近动作

复制提示放在页面底部会被安全区和滚动内容遮挡。触摸动作的反馈应以触摸坐标为锚点。

### 5. 供应商能力要分层验证

账号鉴权成功不等于 TTS 参数正确；握手成功不等于能识别音频；CI 成功也不等于真机权限体验完成。应分别验证鉴权、协议、音频、UI 状态和设备行为。

### 6. CI 的 runner 标签也是依赖

构建失败不一定是代码失败。runner 未分配时任务会在编译前超时；应根据构建步骤状态区分“代码失败”和“基础设施失败”。

- 最终 IPA 已生成，但最终长按、点击朗读、记录回跳仍需在安装后的 iPhone 上逐项确认。
