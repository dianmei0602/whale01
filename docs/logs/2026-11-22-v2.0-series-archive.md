## 1. 2.0 最终状态

鲸鱼 2.0 从“带工具调用的语音助手”升级为本地优先的个人 Agent：

`语音或文字输入 → 理解与规划 → 工具调用 → 本机执行 → 可停止的流式回答 → 工作区沉淀 → 阅读或复盘`

保留三个根入口：助手、发现、待办。工作台作为助手主线能力打开，不增加第四个根 Tab。

## 2. 最终能力

### 助手与工作区

- 首页主任务改为紧凑卡片；全天日历不再占据主任务。
- 无真实工作时显示简短聊天入口，不使用伪造的“待命”内容。
- 每日一句独立展示，支持朗读、展开与复制。
- 工作台包含统一收件箱、项目、私人知识库、晨晚报、阅读、专注和跟进。
- Agent 可调用 `search_workspace`、`save_capture`、`add_followup` 读写工作区。
- 工作区存储包含 schema 版本、旧数据兼容、损坏备份和未来版本只读保护。

### Agent 与工具

- 工具预算为 `min(10, max(3, 任务数 + 2))`。
- 一批工具全部失败且任务多于一步时，每轮最多换路一次。
- 天气、提醒查询、提醒创建、日历查询和网页搜索作为五个核心工具常驻。
- `tools.v1.json` 是工具名称、技能归属和 JSON Schema 的唯一运行时契约源。
- 写操作使用操作预览、权限检查、执行回执和幂等记录。

### 流式回答

- DeepSeek 最终文字回答使用 SSE 增量解析。
- 工具调用参数不会以半截 JSON 的形式显示。
- 用户停止或网络中断时，已收到的半截文字会落成消息。
- 简单问答使用本地快速规划，避免首字等待额外规划请求。
- 首字目标为 1.5 秒，具体设备网络下的实际值仍需真机测量。

### 发现与阅读

- 阅读器复用 `WebContentExecutor` 抽取正文。
- 正文使用原生排版，支持阅读进度、离线缓存、明确失败态和手动 Safari 兜底。
- 自动生成三条重点，每条带段落定位；“为什么重要”仅根据正文结构与数据提示生成。
- 事件聚类使用 36 小时窗口、标题相似度和实体并查集，显示来源家数与相对时间。
- 阅读队列支持待读、在读、读完和进度。
- 阅读摘录与批注直接保存到 `WhaleWorkspace(.reading)`。

### 语音与系统入口

- 语音结果合并到原草稿，可编辑，不自动发送或创建待办。
- 取消、失败和切页恢复原草稿，并通过会话 ID 忽略过期回调。
- App Intents 提供记录到收件箱、打开工作台和朗读今日一句。
- 小组件提供今日一句、下一项任务和工作台深链。
- 分享扩展支持文字、网页、图片和 PDF；无 App Group 时明确拒绝附件传递。
