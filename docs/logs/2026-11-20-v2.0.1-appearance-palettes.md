# 2.0.1 外观配色开发日志

- 日期：2026-11-20
- 版本：`2.0.1 (201.x)`
- 参考：用户提供的“夜海蓝／沙漠红／月苍白”和“亮金／棕红／碧城”两组配色

## 设计决定

外观拆成两个互不冲突的维度：

- 明暗模式：日间、夜间、跟随系统。
- 配色主题：海盐、夜海、鎏金。

切换配色不会改动明暗模式；切换明暗模式也不会丢失已选配色。

## 夜海

参考色直接用于主要语义：

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 夜海蓝 | `#0E4258` | 主操作、选中态、主要信息 |
| 沙漠红 | `#992E34` | 提醒、危险、少量强调 |
| 月苍白 | `#F9F6E5` | 浅色背景、深色文字、高对比标签 |
| 近黑 | `#17100F` | 深色背景基准 |

浅色模式使用月苍白作为页面底色，夜海蓝承担交互，沙漠红只落在注意事项和危险状态。深色模式使用近黑背景，夜海蓝提亮，月苍白承担主文字。

## 鎏金

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 亮金 | `#FBDC92` | 浅色辅助面、深色主文字与主操作 |
| 棕红 | `#944523` | 暖强调、危险与提示 |
| 碧城 | `#0D4D76` | 浅色主操作、选中态 |
| 近黑 | `#0A0907` | 深色背景基准 |

浅色模式以碧城承担主要操作，亮金只作为卡片和柔和面，棕红限制在提示与危险。深色模式以近黑为底，亮金作为文字与操作色，碧城作为次级数据色。

## 无障碍

关键文字组合的对比度：

- 夜海浅色正文／背景：16.23:1。
- 夜海浅色次级文字／背景：5.76:1。
- 夜海月苍白文字／夜海蓝：9.98:1。
- 鎏金浅色正文／背景：16.14:1。
- 鎏金浅色次级文字／背景：5.84:1。
- 鎏金碧城文字／背景：8.10:1。
- 鎏金深色亮金文字／背景：15.01:1。
- 鎏金深色次级文字／背景：11.91:1。

均高于普通文字 4.5:1 的基准。

## 交互

- 设置 > 外观新增三张配色卡。
- 每张卡显示四个参考色块，并提供 VoiceOver 名称、用途提示和选中状态。
- 选择后立即应用，并通过 `AppStorage` 跨重启保存。
- 为 UI 截图增加 `WHALE_DEMO_PALETTE`，可分别验证 `nightSea` 和 `gilded`。

## 当前边界

- 两套主题均提供日间和夜间语义版本，并未把海报中的近黑直接铺到所有页面。
- 品牌图片中的近黑未作为官方色值给出，分别采用 `#17100F` 与 `#0A0907` 作为阅读背景。
- 仍需在真实 iPhone 上检查 OLED、环境光与个人亮度设置下的观感。
