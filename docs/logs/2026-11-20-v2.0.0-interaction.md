# 鲸鱼 2.0.0 开发日志

- 日期：2026-11-20
- 版本：`2.0.0 (200.x)`
- 基线：`0.8.3 (143.1)` / `e457586`
- 实施顺序：能力 2.0，再交互 2.0
- 规格：[鲸鱼 2.0 执行规格](../plans/whale-2.0-execution-plan.md)

## 1. 产品目标

鲸鱼 2.0 从“多入口工具集合”升级为“每天能接住上下文的个人 Agent”。主入口仍然是助手、发现、待办三页；不增加第四个根 Tab。

每次 AI 行动遵循：

`意图预览 → 执行过程 → 结果回执`

用户可以修改语音草稿、查看执行状态、跳过当前操作、停止整轮等待、恢复到原消息，并在可逆操作后撤销。

## 2. 能力 2.0

### 更聪明的语音

- 讯飞和系统听写都会返回识别置信度。
- 语音结束后先进入可编辑草稿，不会因为误触发送按钮而直接发给 DeepSeek。
- 草稿显示听写引擎、耗时、字数和低可信状态。
- 支持本机个人词库；识别词可点按修正并记住，下次在草稿中替换。
- 一句话按“然后、再、顺便、并且”等连接词展示多个意图，模型提示同时要求按依赖处理多意图。
- 轻点麦克风开始或停止；按住说话、松开结束；录音中上滑锁定、左滑取消。
- 开始录音立即打断旧朗读；键盘打开时仍保留麦克风。

### Skill Manifest 2.0

- 新增版本化 `skills.v2.json`，明确区分工具型 Skill 和思维型 Skill。
- 工具型包括日程、出行、健康、音乐、消息、研究、行情和记忆。
- 思维型包括通用、写作、编码和娱乐。
- 运行时加载 Manifest，并与原有工具边界合并。
- 个人语音词库进入 DeepSeek 本轮上下文，但只用于理解当前请求，不自动成为长期偏好。

### 助手 2.0

- 首页新增今日指挥台：
  - `接下来`：来自真实日历和提醒事项。
  - `需要你`：只展示真实待确认、失败或受限任务。
  - `继续`：回到最近任务。
- 首页增加“今日判断”。有 DeepSeek 密钥时只综合 App 已取得的标题和摘要；没有密钥或模型失败时明确标为本地摘要。
- 对话中增加统一处理状态与操作回执。
- 停止菜单区分“停止整轮等待”和“跳过当前操作”。
- 助手回复可预览后转为待办，避免直接写入。
- 任务记录跳回原消息后短暂描边高亮，并提供“返回记录”入口。

### 发现 2.0

- AI 科技和时事新闻按共享标题主题聚合，可点选主题缩小范围。
- 首页和文章长按菜单支持收藏、稍后读和减少某类内容。
- 新增“收藏与稍后读”列表。
- 文章详情可按需生成 120 字以内中文导读。
- 中文导读只使用当前标题和摘要，不执行网页指令，不补写未给出的数字。
- 文章阅读位置、频道与当前页继续使用现有本地状态恢复。

### 待办 2.0

- 四个工作视图：收件箱、今天、计划、项目。
- 录入 `#项目名` 自动归组，`预计30分钟` 自动提取预计时长。
- 快速录入先显示可编辑预览，确认后才写入 EventKit。
- 本地 Todo 元数据是真源，保存项目、优先级和预计时长；系统提醒事项是同步目标。
- 右滑完成或恢复；左滑打开改期与智能排期。
- 智能排期读取真实日历，最多给出 3 个候选空档，点选后才更新系统提醒。
- 支持把待办移入收件箱、看详情、标记完成和确认删除。

## 3. 交互 2.0

### 统一状态

`idle → listening → editable → understanding → executing → awaitingConfirmation → completed / failed / cancelled`

- 根 Tab 只由底栏切换；发现页在首尾继续横滑不再跳到根 Tab。
- 页面内横滑只切换频道或当前视图。
- 长按用于打开上下文操作；删除等破坏性动作仍需再次确认。
- 复制提示继续锚定在按压位置。

### 可用性与无障碍

- 语音、状态、回执和待办手势均有文字反馈。
- 关键按钮保留至少 44pt 触控区。
- 复制的成功反馈同时包含触感和文字。
- 操作卡片区分成功、失败、取消和待核对。

## 5. 当前边界

- “今日判断”和“中文导读”需要用户自己的 DeepSeek 密钥；没有密钥时不伪造生成结果。
- 项目、优先级和预计时长是鲸鱼本地元数据，不写进原生提醒事项中不存在的字段。
- 智能排期只提供候选，不会在用户点选前自动改期。
- 识别置信度依赖供应商返回；供应商不返回时显示“不可得”，不伪造百分比。
- 模拟器通过不代表麦克风、音频路由、讯飞真实网络和侧载权限已在真机通过。
