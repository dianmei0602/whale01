# 2.1.0 Life Agent P0 收口日志

- 日期：2026-11-22
- 版本：`2.1.0 (210.x)`
- 收纳起点：`bccf663`
- 分支：`ui-sea-salt-0.8`
- 对话依赖：ExyteChat `3.3.7`

## 1. 本次目标

把当前 ExyteChat Life Agent 从“本地源码试验”收成可再次验证的 3.0 P0 基线：

- 版本身份只有一处源配置，CI 不再硬编码旧版本。
- 讯飞语音入口回到聊天主流程，听写结果只进入草稿。
- 当前文档明确区分源码候选、已推送构建、IPA 和真机验收。
- 所有能在 Windows 执行的测试先跑通；macOS 独有检查不伪装通过。

## 2. 代码与交互

- `WhaleAgentChatSurface` 使用 ExyteChat 消息时间线，承接文字、照片、文件和长消息菜单。
- 消息行改为微信式布局：头像和气泡顶部对齐，鲸鱼头像固定在左、灰色人像固定在右，
  白色气泡的尖角朝左，蓝色气泡的尖角朝右；工具、确认卡和回执同样靠左排列。
- `ConversationTabView` 增加聊天页语音按钮，复用现有 `VoiceView` 与 `VoiceInputController`。
- 语音听写改为居中浮层：聊天背景模糊，打开即开始识别，卡片显示“正在听…”、
  蓝色波形和红色停止按钮；失败时在同一张卡片内重试。
- 语音结果通过 `WhaleAgentDraftPlan.mergingVoice` 合并到已有草稿，不自动发送。
- UI 测试改用占位文字与无障碍标签定位聊天气泡输入区，并新增语音入口回归。
- `tools/release_identity.py` 统一校验项目、Workflow、README、CHANGELOG、看板和本日志。

## 3. 版本与发布边界

- `ios/project.yml` 为唯一版本源：`2.1.0` / `210`。
- Workflow 通过 `WHALE_MARKETING_VERSION` 与 `WHALE_BUILD_BASE` 读取版本。
- 当前尚未推送构建，没有 2.1.0 IPA，也没有对应 GitHub Actions 运行编号。
- 上一版 `2.0.4 (204.1)` IPA 仍只代表 2.0 系列，不包含 ExyteChat Life Agent。
