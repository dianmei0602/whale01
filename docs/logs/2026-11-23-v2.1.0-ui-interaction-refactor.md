# 2.1.0 UI 交互系统重构日志

日期：2026-11-23  
分支：`ui-sea-salt-0.8`  
计划：[UI 交互系统重构执行计划](../superpowers/plans/2026-11-23-whale-ui-interaction-refactor.md)

## 1. 已完成

- 根导航改为 `RootNavigationModel`，发现页和工作台使用独立 typed path。
- 重复点击当前根入口统一执行 reselect：首页回落地页，发现清空详情，工作台清空导航栈。
- 新增 `TodoTimelineStore`，首页、工作台、完整待办和晨晚报共享同一待办状态。
- “全部待办”从 Sheet 改为工作台 `NavigationStack` 推进页，系统返回和边缘返回恢复。
- 待办详情改为推进页，不再在 Sheet 中嵌套隐藏导航栏的完整列表。
- 删除 `filter`、隐藏统计卡、无效横向滑动等不可达待办交互。
- 工作台知识库、晨晚报和专注拆成独立 SwiftUI 文件。
- 工作台各分区使用独立滚动位置，并增加轻量页面身份区。
- Workspace 的六个并列 Sheet 状态收敛为单一 `WorkspaceSheet`。
- 记录、项目、跟进、摘录和个人资料编辑增加未保存防误滑保护。
- 工作台记录归档与删除增加确认；收藏移除增加撤销。
- 对话、待办、工作台语音输入统一到 `WhaleVoiceCaptureSheet`。
- 语音结束先进入识别结果确认，不再自动写入；取消不修改原草稿。
- 对话页回答处理中允许打开语音听写，只有发送仍受当前轮次限制。
- 首页恢复真实主任务条；工作台空时不再重复显示首页工作台入口。
- 根页面切换、专辑切换和语音波形接入 Reduce Motion。
- 保存、删除、撤销和音乐导入错误增加 VoiceOver 播报。
- 删除确认无引用的五套旧对话/首页实现，共 1365 行。
- IPA 发布默认目录固定为项目 `release/`。
