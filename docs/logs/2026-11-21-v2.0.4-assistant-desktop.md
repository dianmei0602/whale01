# 2.0.4 助手桌面与单一朗读音色

- 日期：2026-11-21
- 版本：`2.0.4 (204.x)`
- 目标：把助手首页从同权重卡片堆叠改为“组件 + 应用图标”的桌面式结构

## 助手桌面

首页现在分为三类视觉对象：

1. 当前任务大组件：显示当前阶段、目标、下一步动作和唯一主按钮。
2. 今天与今日判断组件：在普通字号下并排，在辅助功能大字号下自动纵向排列。
3. 六个应用图标：AI科技、A股自选、游戏动态、我的音乐、时事新闻和热榜，采用 3×2 网格。

应用图标保留滚动摘要和右侧箭头，并使用更清晰的 48pt 图标底、标题和两行实时摘要。大组件、信息组件、每日一句和图标下方都加入低透明度柔和阴影，不使用高对比描边或发光。

## 桌面整理

- 长按任一应用图标进入整理模式，所有图标产生轻微交替晃动。
- 整理状态支持拖动排序、减号隐藏、全部恢复和恢复默认顺序。
- 设备开启“减少动态效果”时不晃动，但仍可排序和隐藏。
- 顺序与隐藏状态通过本机偏好持久化。
- 除长按外还提供可访问的“整理”按钮，避免只能依赖手势。

## 朗读

- App 内朗读移除 `AVSpeechSynthesizer` 系统音色回退。
- `SpeechPlaybackController` 只请求讯飞 TTS，请求参数固定 `vcn=x4_yezi`。
- 未配置讯飞或合成失败时停止播放并显示错误，不静默切换系统朗读。
- 每日一句新增小露朗读按钮；聊天、资讯标题/摘要和设置试听继续共用一个朗读控制器。
- 系统辅助功能中的“朗读所选内容”由 iOS 控制，不属于 App 内朗读入口。
