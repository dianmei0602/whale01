# Nomi 1.7 · M1 + M2 + 暗色改版

日期：2026-11-15
版本：`1.7 (21)`
范围：只动"手感"和"颜色"，不动角色本体、不改业务逻辑

## 一、M1 动效地基

- 新增 `NomiMotion` 四档令牌（fast / base / slow / settle），全 App 不再各写魔法 spring 参数。
- `WhalePressStyle` 升级：按压缩放 0.975 + 变淡 + **轻触觉**（`sensoryFeedback(.impact(.light))`）；
  开启「减弱动态效果」时只变淡不缩放。已有 53 处按钮自动生效。
- 数字翻滚（`contentTransition(.numericText())`）：记录页完成数、首页倒计时、行情涨跌幅、资讯计数。
- 字号语义上调：资讯标题 12.5 → **15**、来源元信息 9.5 → **12.5**、记录页副标题 11.5 → **13.5**；
  配合此前 `nomiScaled` 下限 11.5 → 12.5，全 App 无小于 12.5 的文字。

## 二、M2 交互

- **主卡栈**：首页顶部三张卡（下一件事 / 天气 / 步数），系统分页 + 惯性 + 切页触觉 + 指示点。
  第一张用的是原本未被使用的 `whaleNextAction` 数据，没有新增查询。
- **输入坞弹簧抽屉**：上推输入坞 → 拉开对话；首页 ↔ 对话过渡统一走 `NomiMotion.base`。
- **切 Tab**：分页动画改用 `NomiMotion.slow`，换页给一次选择触觉。
  （没有做"圆形展开"：现有左右滑动分页会与它抢手势，反而更差。）
- 新增 `openChat()` / `closeChat()`，替换原先散落 6 处的不同动画。

## 三、暗色改版（深海绿 → 暖炭黑）

用户反馈：原暗色整套偏绿（底 `#07131A`、强调 `#62EAD6`、分隔线偏绿），像"深绿玻璃"。

三套候选：`docs/preview/palette-options.png` → **选 B 暖炭黑**。

| 页面底 | `#07131A` | `#0C0A09` |
| 更深层 | `#040B10` | `#050403` |
| 卡片面 | `rgba(12,33,41,.72)` | `rgba(26,22,19,.78)` |
| 强卡面 | `rgba(15,40,49,.94)` | `rgba(32,27,23,.95)` |

| 次强调 | `#78B9FF` | `#D98E6A` |

- 亮色「晨雾」保持不变
- 全部走语义色，页面代码零改动；已确认无绿色残留

## 五、真机要确认

1. 首页三张卡能左右甩，切换有轻触觉，指示点跟随
2. 上推输入坞能拉开对话，返回首页有弹簧过渡
3. 点任何按钮：缩一下 + 轻震；开启「减弱动态效果」后不缩放
4. 数字变化（倒计时/完成数/涨跌）是翻滚，不是硬跳
5. 暗色下整体是暖炭色，不再泛绿；亮色仍是晨雾
6. 钛合金 Nomi 本体、底部三入口、设置入口、音乐来源、资讯中文等不变量均未变
