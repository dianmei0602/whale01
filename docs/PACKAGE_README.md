## 设计基线

- 真机设计稿：`design/ui-design-iphone16pro.html`
- 画布：iPhone 16 Pro，402 × 874 pt，@3x 为 1206 × 2622 px
- 默认配色：素瓷（浅色）/ 夜墨（深色）
- 角色：钛合金外壳、黑玻璃脸、两只青色竖眼、脖子和两只金属脚
- 表情：九档，与 `PetMood.swift` 使用同一套参数
- 完整角色尺寸：96–132 pt；对话角色 52–88 pt；小头像 24–36 pt
- 灵动岛：compact / minimal 只使用眼睛局部符号

## 后续交互要求

设计稿确定后新增的要求继续生效：

- 小头像为黑底双蓝眼图标，不替代首页完整角色
- 输入栏不显示 Nomi 头像
- 底部主入口包含 Nomi、今日和设置
- 对话与今日页支持左右滑动返回 Nomi 首页
- 键盘支持下滑、点空白、发送和开始语音时收起
- Nomi 可拖到输入栏上方区域，松手有回弹与触感反馈

## 目录

- `ios-app/`：当前 iOS 工程、设计规范、开发日志和预览资料
- `assets/`：角色、图标、渲染、语音样例、PWA 与交互设计资产
- `design/`：iPhone 16 Pro 设计稿及关键效果图
- `build/`：已验证的 IPA（若本次构建产物可下载）
- `MANIFEST.sha256`：归档文件校验值

## 安装

1. 下载 `build/Jinri-unsigned.ipa`
2. 使用 Sideloadly 或自己的签名工具安装
3. 免费签名下，小组件无法使用 App Group 共享数据，只能显示降级状态
4. Live Activity 只能在系统允许的时间点更新，不做逐秒常驻动画
