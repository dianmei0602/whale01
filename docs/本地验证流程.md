# 本地验证流程

> 目的：**别每改一行都打包上手机。** 只有真机才能验的东西才值得走 CI。

## 三步分工

| 要验证的东西 | 用什么 | 一次耗时 |
|---|---|---|
| 布局 / 颜色 / 字号 / 交互 | `docs/preview/preview.html` | 秒 |
| 音色 / 语速 / 音高 | `voice-samples/index.html` | 秒 |
| 麦克风 / 灵动岛 / 传感器 / 权限 | 打包上手机 | 5–10 分钟 |

## ① UI 预览：`docs/preview/preview.html`

用浏览器直接打开（双击即可，不需要服务器）。

顶部三个切换条：

```
[浅色 | 深色]   [Nomi | 今日 | 日程 | 设置]   [待机 | 在听 | 在想 | 聊天中]
```

支持 URL 直达，方便截某一张：

```
preview.html#page=settings&theme=dark
preview.html#page=nomi&state=chat&theme=dark
preview.html#page=schedule&theme=light
```

**能验证**：字号够不够、间距顺不顺、浅色深色是否统一、卡片长什么样。

**改法**：直接改文件里的 CSS（每个值旁边有注释），存盘刷新浏览器即可。

**改完对齐**：把确认过的数值同步到 Swift 里（`CardPalette`、`AssistantView` 的字号等）。

## ② 语音试听：`voice-samples/index.html`

**不用装 App 就能听音色。**

```
① 先选音色      7 个可用音色，同一句话，语速 50 音高 50
② 再调参数      x4_yezi × 6 组语速/音高
③ 换音色对比    x4_qingqing × 6 组
```

### 重新生成样品

```bash
# 所有音色（会打印哪些授权、哪些 licc failed）
python tools/xunfei_voices.py voices

# 某音色的 6 组语速/音高
python tools/xunfei_voices.py tunes x4_yezi
```

生成完重新跑一遍页面生成（或直接刷新，mp3 文件名是固定的）。

### 参数的含义

| 参数 | 5 0 = ? | 建议范围 |
|---|---|---|
| `speed` | 正常语速 | 42–56 |
| `pitch` | **真人原始音高** | 45–55 |
| `volume` | 正常音量 | 60–85 |

**`pitch` 不要低于 45。** 讯飞是对真人录音做变调，压得越多电音味越重——之前压到 38 就是"很假"的原因。

## ③ 什么时候才打包

必须上真机的：

- 麦克风 / 语音识别

- 陀螺仪、摄像头、步数、定位

- 小组件

**其余全部先在① ② 里确认。**

## 本地自动检查（每次改完 Swift 跑）

```powershell
# 语法
Get-ChildItem App -Recurse -Filter *.swift | % { swiftc -parse $_.FullName }

# 五道检查器
python tools/check_files.py            # 0 字节文件
python tools/lint_ternary.py App/Sources   # 三元两边类型
python tools/check_targets.py          # extension 引用 App 专属类型
python tools/check_enum_switches.py    # switch 漏 case
```

挡不住的：**确定初始化、元组 keypath、泛型推断** —— 只能等 CI。

## 打包到手机的步骤（确认后再做）

1. GitHub Desktop → Push origin
2. 等 Actions 变绿（约 3–5 分钟）
3. 下载 `Jinri-unsigned` artifact
4. 双击桌面 **`Sideloadly（走代理）.cmd`**（不要点 Sideloadly.lnk，会报更新检查错误）
5. 拖 IPA → 填 Apple ID → Start
