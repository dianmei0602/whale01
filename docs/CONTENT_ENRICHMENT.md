# 编年史内容扩充方案

## 当前基线

首版内容适合验证信息架构，完成第一批扩充后的当前版本已进入可读阶段：

- 23 个政权或时期条目
- 57 个事件档案，每个事件具备背景、经过、结果和意义
- 66 位人物档案
- 23 个历史地点
- 31 个制度与文明主题
- 25 个传统文献与研究参考
- 辽、西夏、金均已建立独立事件条目
- 事件时间全部精确到年，尚未记录月份、日期或更细的学术说明
- 已建立独立的人物、地点和制度主题实体
- 主要事件已增加第二类交叉文献，但仍需继续定位到更精确的篇章和版本

扩充后仍需继续增加可定位的文献证据和争议材料，不能只满足于摘要长度增加。

## 内容模型

### 1. 骨架：政权与时代

每个政权除现有简介外，补充：

- 君主和年号序列
- 都城迁移
- 制度关键词：中央官制、地方行政、军制、选官、赋税
- 主要区域和并存政权
- 建立、转折和终结的节点
- 3–5 条延伸阅读路线

### 2. 节点：历史事件

事件不应只有一段摘要。建议每条事件至少包含：

- 发生了什么
- 为什么会发生
- 如何发展
- 产生了什么后果
- 涉及哪些人物、地点和政权
- 为什么值得放进主线
- 资料分歧或纪年提醒
- 至少两个可追溯出处

建议正文长度：

- 时间轴一行摘要：20–35 字
- 详情页摘要：80–140 字
- 完整事件档案：200–500 字
- 每条事实都能回指来源；观点和推测单独标记

### 3. 人物

人物不是简单姓名列表，至少需要：

- 姓名、别名、生卒年
- 身份与主要职位
- 所属政权
- 关键事迹
- 与其他人物、事件的关系
- 传记出处

第一版只收“能改变制度、战争、文化或政治格局”的人物，避免变成没有关系的名人卡片。

### 4. 地点

地点需要同时表达历史位置和现代认知：

- 历史名称与现代位置
- 在不同时期的功能
- 对应事件与政权
- 是否可以在地图上定位
- 名称变化和地望争议

例如“长安”不是一条静态地点记录，而是西汉、隋、唐等时期不同政治和历史语境中的节点。

### 5. 制度与文化物证

增加三类专题内容：

- 制度：郡县、科举、三省六部、行省、军户等
- 技术：造纸、印刷、火药、航海、农作等
- 物证：青铜器、简牍、文书、绘画、建筑、考古遗址

每项物证至少记录：

- 年代与出土地或收藏地
- 与哪个时代/事件相关
- 它证明了什么，不能证明什么
- 图像授权与来源

## 页面呈现

内容累积以后，按以下方式进入现有界面：

1. **长河**：每个事件显示为年份节点；选中年份显示“同年事件”和“并存政权”。
2. **政权详情**：分成“时代骨架 / 转折事件 / 制度与生活 / 出处”四段。
3. **并立**：比较同一年的政权，不把接替关系误画成并行关系。
4. **人物与地点索引**：从事件详情反查人物、地点和其他事件。
5. **主题路线**：例如“从分封到郡县”“辽宋夏金百年”“制度如何维持帝国”。

## 当前覆盖

第一轮已经覆盖六个时代：

- 23 个政权均有制度、社会和影响说明
- 57 个事件均有背景、经过、结果、意义和至少两个来源
- 66 位人物、23 个地点、31 个主题可与政权和事件互链
- 辽、西夏、金均已建立独立事件条目

这使用户能从任意主题进入政权、事件、人物和出处，但还只是高质量的内容骨架，不是完整学术数据库。

## 后续深化顺序

### 第一批：文献定位

优先把现有书目级引用细化到篇、卷或章节，并为争议较大的年代和解释增加至少第二种研究观点。

### 第二批：人物与制度关系

补充人物之间的君臣、师承、亲属、盟友与对手关系；为制度变化增加前后阶段和地区差异。

### 第三批：地理与文化物证

加入可定位的历史地图、考古遗址、器物与图像，并严格记录收藏地和授权。

### 第四批：专题路线

围绕“从分封到郡县”“辽宋夏金百年”“制度如何维持帝国”等主题组织跨时代阅读路径。

## 编辑流程

每个内容批次固定经过四步：

1. 从原典或可靠研究摘录事实，保留章节或页码。
2. 建立结构化事实卡，不直接让模型写最终文案。
3. AI 仅用于压缩、改写和建立索引，不得补造人物、时间、地点或结论。
4. 人工复核年代、人物关系、出处和争议说明，再进入 App 数据。

## 验收标准

一批内容完成必须同时满足：

- 没有无出处事件
- 没有无法落地的引用 ID
- 每个政权页面至少有 3 个可读节点
- 并存政权在同一时间尺度上能正确解释
- 有争议的年份和解释显式标出
- 手机端能在一分钟内找到“发生了什么、为什么会发生、依据是什么”
- 数据校验、Web 演示和 iOS 数据保持同源
