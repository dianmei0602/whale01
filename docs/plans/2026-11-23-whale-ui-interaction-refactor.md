# 鲸鱼 001 UI 交互系统重构方案

日期：2026-11-23  
基线：`fce952c33e257ebc7e7cb60a6a9cd15c8028e951`  
范围：三个根入口、工作台内部导航、待办详情、统一语音入口、反馈和可访问性

## 1. 审核结论

当前页面不是缺少个别按钮，而是缺少三套统一规则：

1. 什么内容应该推进页面，什么内容应该弹出 Sheet。
2. 一个页面由谁管理返回路径，以及是否允许根页面横向滑动。
3. 所有语音输入是否共享同一套会话状态、视觉和结束方式。

用户看到的工作台问题，都是这三套规则缺失后的结果。

## 2. 已核实问题

### P0：点击「全部」后没有可见返回路径

证据：

- `WhaleWorkspaceView.swift` 用布尔状态 `showTodoManager` 打开待办 Sheet。
- 外层 `NavigationStack` 设置了「完成」工具栏按钮。
- 内部 `TodoView` 固定执行 `.navigationBarHidden(true)`，把外层工具栏一并隐藏。

根因：把本该推进页面的主任务列表放进了 Sheet，同时子视图自行控制导航栏。修复时不能只补一个悬浮关闭按钮，应改成根级页面推进，让系统返回按钮、边缘右滑和状态恢复自然成立。

### P0：语音入口不是同一套系统

当前有三类实现：

- 对话页：顶部麦克风打开 310pt `VoiceView` Sheet，自动录音。
- 待办页：麦克风在输入框内原地录音，显示独立的内嵌录音条。
- 工作台记录页：工具栏按钮开始录音，文字直接写进编辑器，没有统一波形和结束反馈。

根因：每个页面各自持有 `VoiceInputController`、草稿前缀、识别回调、错误恢复和按钮状态。底层听写能力相同，但用户看到的开始、停止、确认、取消和失败恢复不同。

### P1：工作台使用多个并列布尔 Sheet

`WhaleWorkspaceView.swift` 同时维护记录编辑、记录详情、项目、跟进、待办、阅读、摘录等布尔值或可选状态。它们共享同一父视图但没有单一展示状态，容易出现叠层、重复关闭逻辑和状态竞争，也让返回路径难以审计。

### P1：根页面、发现页、工作台的导航模型不一致

- 根容器使用分页 `TabView`。
- 发现页自带 `NavigationStack`。
- 工作台没有根导航栈，只用 Sheet。
- 待办内部再次创建 `NavigationStack`，然后被放进工作台 Sheet。

同样是“进入下一层”，系统返回、右滑、关闭方式和状态恢复完全不同。

### P1：横向手势边界不清

根页面可横向分页，工作台分区栏、待办筛选、发现频道、卡片滑动和系统返回都可横向操作。没有统一优先级，用户无法预测一次横向拖动是在切根页面、切频道、切筛选还是返回上一页。

### P1：工作台信息架构重复

工作台同时存在：

- 待办摘要和「全部」；
- 待办全量页自己的筛选和分组；
- 收件箱、项目、晨晚报、知识库、阅读、专注、跟进七个分区。

概览、列表和编辑混在同一长页面里。用户能看到很多能力，但不知道哪些是浏览、哪些会进入下一页、哪些会写数据。

### P2：交互反馈和可访问性未形成统一契约

按钮已有按压反馈，但异步提交、弹层关闭、失败恢复、撤销、键盘与录音切换仍由各页面分别处理。UI 测试只确认「全部」按钮存在，没有验证进入后能返回，也没有验证三个语音入口一致。

## 3. 目标交互模型

### 3.1 三个根入口保持不变

- 首页：每日一句、当前任务、开始对话。
- 发现：资讯、行情、游戏等探索内容。
- 工作台：待办摘要和鲸鱼工作区概览。

不把所有能力塞回聊天，不再增加第四根入口。

### 3.2 每个根入口拥有独立导航栈

根容器保留分页 `TabView`，但每个根页包裹自己的 `NavigationStack(path:)`：

- `HomeRouter`
- `DiscoverRouter`
- `WorkspaceRouter`

每个路由只保存轻量 `Hashable` destination，不保存具体 View。切换根入口时保留各自己的返回路径和滚动位置，重复点击当前根入口回到该入口首页。

横向手势规则：

1. 子页面非空时，左缘右滑优先执行页面返回。
2. 子页面为空且没有正在编辑的横向控件时，才允许切换根入口。
3. 工作台分区栏、待办筛选等局部横向控件使用自身手势，不触发根页面切换。

### 3.3 推进、弹层和沉浸页只承担一种语义

| 交互 | 使用方式 | 例子 |
| --- | --- | --- |
| 页面推进 | 浏览下一层、查看全部、进入详情 | 工作台 → 全部待办 → 待办详情 |
| Sheet | 一个短任务，完成后回到原处 | 快速添加、语音输入、确认写入 |
| 全屏页 | 长时间沉浸内容 | 原文阅读、媒体预览 |

硬规则：

- 主列表不能塞进 Sheet。
- Sheet 内不再叠一个隐藏外层导航栏的主列表。
- 编辑类 Sheet 顶部必须有明确的取消和完成；有未保存内容时确认是否丢弃。
- 所有 Sheet 由单一 `SheetDestination` 管理，避免同一父视图挂七个布尔 Sheet。

### 3.4 统一语音会话

新增共享 `VoiceCaptureSession` 和唯一的 `WhaleVoiceCaptureSheet`：

```text
idle
  → requestingPermission
  → listening
  → finalizing
  → reviewing
  → committed / retry / cancelled
```

统一行为：

- 点击任何麦克风都先收起键盘，再从底部打开同一个语音 Sheet。
- 权限允许后自动开始；权限拒绝时解释原因并提供系统设置入口。
- 录音中显示实时文字、波形、时长和大触控停止按钮。
- 停止后先展示可编辑的识别结果，再选择「填入」或「重试」。
- 下滑取消会恢复原草稿，不丢已有文字；取消有触觉反馈。
- 网络、电话打断、无麦克风等失败使用同一错误模型和恢复动作。

三个入口只传入不同上下文：

- 对话：`给鲸鱼说`，结果填入聊天输入框，不自动发送。
- 待办：`记一件待办`，结果填入待办输入框并进入解析预览。
- 工作台：`记到工作台`，结果填入记录编辑器。

说话、识别、修正和确认的体验保持一致；写入目标仍由各业务页面决定。

## 4. 工作台重构

工作台首页只承担概览和入口：

1. 顶部待办摘要：展示最近 4 项、快速添加、查看全部。
2. 工作台分区：收件箱、项目、晨晚报、知识库、阅读、专注、跟进。
3. 每个分区的「查看全部」推进到独立列表页，不在首页无限展开。
4. 条目详情推进到详情页；新建记录、新建项目等短任务继续使用 Sheet。

建议路由：

```swift
enum WorkspaceRoute: Hashable {
    case todos
    case todoDetail(id: String)
    case inbox
    case capture(id: String)
    case projects
    case project(id: String)
    case knowledge
    case reading(ReadingRoute?)
    case focus
    case followUps
}
```

「全部」改为 `router.push(.todos)`。返回按钮和边缘右滑由 `NavigationStack` 负责；待办筛选与分组保留在列表页内部。

## 5. 分阶段执行

### 阶段 0：冻结基线并补失败测试

- 为「工作台 → 全部 → 首条详情 → 返回 → 返回工作台」增加 UI 测试。
- 为对话、待办、工作台三个语音入口增加统一标识和状态测试。
- 记录当前视觉截图，区分 UI 回归和有意改版。

### 阶段 1：导航外壳

- 新增根级路由枚举和每根入口独立路径。
- 工作台增加 `NavigationStack`，「全部」改为推进页。
- 清理 `TodoView` 在嵌入场景中自行隐藏导航栏的行为。
- 明确根分页与子页面右滑的手势优先级。

验收：所有进入路径都有系统返回；重新点当前根入口回到该根首页；UI 测试完整通过。

### 阶段 2：工作台信息架构

- 首页收敛为概览和分区入口。
- 列表、详情、编辑三种页面分开。
- 引入单一 `WorkspaceSheet` 状态，移除并列布尔 Sheet。
- 保留现有真实数据、权限和确认写入边界。

验收：工作台不出现同一功能多个入口；空态不占大版面；长列表不在首页展开。

### 阶段 3：统一语音

- 抽取共享语音会话状态机和底部 Sheet。
- 对话、待办、工作台全部切换到同一组件。
- 移除页面级重复的录音回调、内嵌录音条和独立错误恢复。
- 保持讯飞优先、系统听写降级和真实失败提示。

验收：三个入口的权限、录音、停止、重试、取消和插入行为一致；取消不丢原草稿。

### 阶段 4：反馈、可访问性和清理

- 统一按钮忙碌、禁用、成功、失败和撤销状态。
- 统一 44pt 触控目标、VoiceOver 标签、动态字体和减少动态效果。
- 在确认无引用后处理 `ChatView`、旧 `ConversationSurface` 等死代码。
- 模拟器 UI 回归后做真机手势和讯飞听写验收。

## 6. 验收清单

- 工作台「全部」进入后，导航返回、边缘右滑、再次点击工作台根入口都能回到工作台首页。
- 待办详情从列表推进，不再套在同级 Sheet 中。
- 三个麦克风入口使用同一视觉、状态和错误恢复。
- 语音取消恢复原草稿；停止后可以检查再插入。
- 页面横向滑动不与列表、筛选和系统返回抢占。
- 所有 Sheet 只有一个展示源，关闭路径可预测。
- 所有异步操作都有可见进度，失败不伪装成功。
- UI 测试、单元测试、Swift 语法检查、Xcode 编译、侧载构建依次通过。

## 7. 本轮不做

- 不改三个根入口的产品定位。
- 不恢复工作台式重布局或新增入口。
- 不为了统一语音而虚构系统能力或自动发送。
- 不在同一提交里混入大规模视觉重做、数据迁移和语音架构改造。

```text
release/WhaleAgent-Sideload.ipa.sha256
```
