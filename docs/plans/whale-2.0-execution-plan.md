# 鲸鱼 2.0 执行规格

- 日期：2026-11-19
- 基线：`0.8.3 (143.1)`
- 实施顺序：能力 2.0，然后是交互 2.0
- 总原则：保留三个主入口；所有 AI 行动经过“意图预览 → 执行过程 → 结果回执”；写操作确认、可停止、可撤销、可回到原上下文。

## 1. 能力 2.0

### 语音

- 听写结果先成为可编辑草稿，不因松手或误触自动发送。
- 本地个人词库在提交给模型前修正专有名词；只做可解释的替换。
- 一句话包含多个请求时，按“然后、再、顺便、并且”等连接词拆成意图预览。
- 草稿显示听写引擎、耗时、字数和待核对项，便于区分权限、网络和识别问题。

### 助手

- 首页固定展示“接下来、需要你、继续”三层信息。
- “接下来”来自真实日历与提醒事项。
- “需要你”只展示真实待确认、失败或待授权事项。
- “继续”回到最近任务记录；原消息定位后短暂高亮。
- 对话展示执行状态和最近操作回执，不展示模型内部推理。

### 发现

- 新闻按共享主题聚合，进入文章后可收藏、稍后读和生成中文导读。
- 英文标题或摘要提供按需翻译；翻译失败时保留原摘要并明确失败。
- 每个频道和文章保留阅读位置，加载失败不覆盖最后一次成功内容。

### 待办

- 四个视图：收件箱、今天、计划、项目。
- 本地 `TodoItem` 元数据保存项目、优先级、预计时长和来源；EventKit 仍是系统同步目标。
- 快速录入先展示项目、截止时间、预计时长，再确认写入。
- 智能排期读取真实日历，提供 1～3 个候选空档，写入前确认。

## 2. 交互 2.0

### 全局状态机

`空闲 → 正在听 → 可编辑 → 正在理解 → 正在执行 → 等待确认 → 完成／失败／取消`

- 主 Tab 只由底栏或根级手势切换。
- 页面内横滑只切换频道或当前视图内的标签。
- 长按只打开上下文操作，不直接执行删除等破坏性动作。
- 主要操作同时具备触感、文字状态和 VoiceOver 描述。

### 语音手势

- 轻点麦克风开始或停止。
- 按住说话，松开结束。
- 录音中上滑锁定连续录音。
- 录音中左滑取消。
- 识别结束进入草稿预览；低可信内容可点击修正。
- 开始录音立即打断旧朗读。

### 助手

- 停止分两层：停止当前等待步骤，以及停止整轮。
- 回答可转待办、日程或笔记；所有写入先预览。
- 任务记录回跳后高亮原消息，并提供“返回记录”。

### 发现

- 轻点段落朗读，再点暂停；长按复制该段。
- 收藏、翻译、稍后读和减少此类内容放在详情或长按菜单。
- 从文章返回时恢复频道和卡片位置。

### 待办

- 点击圆圈完成或恢复；点击正文查看详情。
- 右滑完成或恢复；左滑改期或移入收件箱。
- 长按调整优先级、项目、提醒时间和删除。
- 删除入口远离完成入口，必须再次确认。

## 3. 交付门槛

- 新领域模型均有单元测试。
- 旧测试全部通过。
- GitHub Actions 完成 app 与测试目标编译。
- 修改公开数据、EventKit 或语音链路时，分别执行模拟器回归与真机验收。
- 只有在真实工具成功后才显示“已完成”。
