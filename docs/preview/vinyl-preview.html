结构

  • 顶部：黑胶唱片（播放时转，暂停停）＋唱臂
  • 中间：歌名 / 歌手 / 一句状态
  • 下部：进度、上一首/播放/下一首
  • 底部：当前歌单，点「换歌单」回列表

页面藏哪

  • WKWebView 放到屏幕外（1×1 像素），只听不看
  • 后台播放靠 UIBackgroundModes: audio（项目已有）
  • 曲目信息用 JS 每秒取一次，取不到就降级

为什么不是"真播放器"

  • 网易云无公开播放 SDK，无法直接拿音频流
  • 所以黑胶界面的"播放"本质是控制网页里的 <audio>
  • VIP/版权曲目可能只有网页能播、或根本不能播
