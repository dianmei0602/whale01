Design Language · v4 · iPhone 16 Pro / Asset Restoration

按真机尺寸重画，角色一个零件都不改

这一版继承 v3 的当代材质语言与 5 套语义配色，只做两件事：画布对齐 iPhone 16 Pro 的 402 × 874 pt（含灵动岛与安全区的精确尺寸），以及把 Nomi 恢复成项目里既有的钛合金虚拟机器人——九档表情、眨眼、视线跟随、说话表情节拍、看见你就笑，全部原样沿用。

先纠错：v2 / v3 我把角色改成了「白色陶瓷器物 + 蚀刻槽 + 亮度三档」，并把四态情绪光删掉。这违反了 ios-app/docs/design-c/nomi-c-implementation.md §0：「钛合金机器人本体、眼睛参数、表情和动作是 Nomi 的核心产品资产，不是可替换的装饰图标」。表情系统是产品功能，不是视觉风格的可选项。本稿以此为准，v2 / v3 的角色方案作废；布局、材质与配色资产保留。

最容易错的一处：「灵动岛宽度 230pt」不是硬件药丸的宽度。硬件岛是 126×37pt；230pt 是 HIG 给的 compact / minimal 呈现时内容可用的总宽——左右各 52.33pt 的内容区加上中间 125.34pt 传感器区，正好 230pt。把这两个数混用，岛内布局一定会被系统裁掉。
另一处：项目 island-integration.md 里的模拟岛是 132×37，是 14 Pro 时代的近似值；16 Pro 应按 126×37 重画。
03

九档表情 · 原样沿用

数值逐条取自 PetMood.swift，展板按 3× 放大便于看形；卡片上标注的是原始 pt 值。点任意一张，所有真机稿、小头像与灵动岛里的角色同时切到该表情——同一张参数表驱动所有尺寸，网页版与 SwiftUI 版才不会漂移。

今天的卡片 / 时机表情为什么是这张脸

表情不是装饰，是规则的输出

同一套 RulesEngine 先决定「有没有事、是什么事」，再决定「它用什么脸看你」。所以九档一条都不丢，它们变成规则引擎的显示层。

· 眨眼 2.5–7.5s 随机，22% 连眨；朗读时再快 20%（blinkSpeed = 0.45）
· 表情节拍 SpeechPerformance 把回答切句判语气（没拿到 / 提醒 / 商量 / 答应了 / 温和 / 陈述），念到哪句脸跟着变
· 视线跟随 眼睛位移 3.5→7.0；followFace 默认关（隐私），回前台自动恢复
· 看见你就高兴 hasFace false→true：happy + 蹦一下 +「你来啦」，6 秒冷却
· 物理盒子 点击、长按、拖动、探头性格全部保留
真机限制：岛内只能用 SwiftUI 有限子集，CSS 那套 60fps 常驻循环搬不过去，要改成「状态驱动的一次性动画」（island-integration.md §4）。这是实现方式变化，不是表情系统变化。
04

角色尺寸梯度 · 六档

照 nomi-c-implementation.md §0 的使用层级表。所有档位共用同一个 200u×250u 组件，只改 --u——头身比例永远是原样，绝不把整个角色压成一个矩形头像。最后一档是「黑底双蓝眼」小图标，它只用于小头像，不能代替首页与锁屏里的完整角色。

9pt 的必然结论：pet-look.html 里那句「脸的直径不到 9 像素，大图是给你调形用的」是对的。灵动岛 compact 里脸只有 9–12pt，只要眼睛、没有嘴是尺寸逼出来的，不是审美偏好。九档里靠眼宽 8.4–10.8pt、间距 6.2–9.6pt、眼睑 0–78% 的差别，在 9pt 下仍可区分；arcUp / arcDown 的 2.8–2.9pt 弧线是下限，不能再细。

07

五套配色 · 界面可变，角色不可变

v3 的语义配色资产继续沿用（21 个变量、同一份 CSS、每套 12 项对比度全达标）。唯一变化是边界：眼睛青色、辉光与黑屏被移出配色系统，成为角色常量。换到哪一套，Nomi 都还是同一个 Nomi。

08

验收清单

把「尺寸正确」和「资产没被动过」写成可断言的条目，避免下一轮改稿又把它改回去。

  • 画布严格 402 × 874 pt，@3x 导出 1206 × 2622 px
  • 所有标题 / 按钮 / 输入坞落在 62pt 顶、34pt 底、20pt 左右安全区内
  • 硬件岛 126 × 37 pt、y=11；不得沿用旧的 132 × 37
  • compact 内容宽 230pt（52.33 + 125.34 + 52.33），minimal 36.67–45pt
  • expanded 与锁屏 LA 371 × 84–160pt、圆角 44pt
  • Home Indicator 140 × 5pt、bottom 8pt；Tab Bar 49 + 34 = 83pt
  • 九档表情 ID、数值、顺序与 PetMood.swift 完全一致
  • 规则映射（nil→sleep / todo→sideeye / meet→focus / sport→excited …）不得改写
  • 眨眼、视线跟随、说话表情节拍、看见你就笑、物理盒子全部保留
  • 角色 6 档尺寸共用 200u×250u 组件，头身比例不变
  • 眼睛 #5CEBFF / 辉光 / 黑屏不进入配色变量，五套一律不覆盖
  • 岛内只放眼睛局部符号；小头像不得替代首页与锁屏的完整角色
  • 所有可点区域 ≥ 44 × 44pt；深色/浅色文字均通过 AA 对比度
  • Live Activity 不常驻，更新点只在有意义的时间，无静音音频
  • prefers-reduced-motion 下常驻呼吸与循环动画降级
