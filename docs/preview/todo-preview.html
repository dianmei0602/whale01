写操作：不确认不写

  • 说「加个待办」→ 先出确认卡（标题 / 时间 / 清单）
  • 默认按钮是「算了」，风险按钮写清动作（确认添加）
  • 确认后出回执，失败要说失败，不静默

数据：只有一份

  • 读写都走系统提醒事项（EventKit），不建第二张表
  • Siri / 提醒事项 App / 手表天然同步
  • 没给权限 → 整个待办区隐藏，其余卡照常

文案：给结论，不给选项

  • 逾期只把日期染成琥珀，不整行染红
  • 完成保留 1.5 秒「已完成」回执，状态不突然消失
  • 数字必须有：18:00、拖了 2 天，不写「该做了」
