采用的动效（12 条）

  • 卡栈 + 惯性甩卡物理手势 左右甩切卡，回弹归位
  • 弹簧抽屉物理手势 输入坞上推成全屏对话
  • FLIP 共享元素形变转场 卡片点开 → 详情连续放大
  • 果冻按压微交互 所有可点元素 + 触觉反馈
  • 波纹扩散微交互 图标与快捷按钮点击
  • 数字翻滚文字排版 倒计时 / 步数 / 进度百分比
  • 逐行顶上来入场揭示 资讯与待办列表首屏
  • 骨架流光加载进度 资讯加载占位
  • 描边生长加载进度 完成率圆环
  • 长按进度环微交互 长按「完成」防误触
  • 圆形展开形变转场 切 Tab 时的背景过渡
  • 光晕呼吸氛围背景 背景光斑，30 秒一个周期

明确不采用

  • 片元着色器（极光/液态球/万花筒）——耗电、发热，和"安静陪伴"冲突
  • 画布粒子（烟花/星空/拖尾）——只在「玩一下」里保留物理盒子
  • 3D 翻转 / 透视倾斜——对信息型界面是无谓的视觉噪音
  • 故障抖动 / 字符扰乱——情绪不对，显得吵
  • 逐字打字机——长句会拖慢阅读，只在语音字幕里保留
  • 粒子迸发——只用于「完成待办」一次，别处禁止

落地方式

  • 统一动效令牌：快 180ms / 中 320ms / 慢 520ms，弹簧 response .34 / damping .78
  • 全部走 SwiftUI 原生：.spring、matchedGeometryEffect、contentTransition(.numericText)、.sensoryFeedback
  • 遵守 reduceMotion：关掉位移与旋转，只留淡入
  • 角色本体零改动：只加"出现/退场"的容器动画，不动钛合金、眼睛、表情
