# Nomi 1.7 · 动效化 UI 方案

> 依据：`D:\AI_work\交互动效库`（100 条配方 / 10 类引擎）
> 视觉稿：`docs/preview/ui-1.7-motion.html`、`docs/preview/ui-1.7-motion.png`
> 原则：**不动角色本体**，只重排信息层级 + 加"有意义的动"。

---

## 1. 现在的问题

| 问题 | 表现 |
|---|---|
| 层级平 | 首页主卡、快捷行、小卡、输入坞都在同一层，眼睛没有落点 |
| 动作"跳" | 页面切换、列表出现、数字变化都是瞬间替换，没有过渡 |
| 点按无反馈 | 按钮只有颜色变化，没有按压/触觉，"按了没按"不确定 |
| 加载是空白 | 资讯刷新时直接空屏，等 1–3 秒像卡死 |
| 氛围静 | 背景是静态渐变，角色在动、界面不动，割裂 |

## 2. 选型：从 100 条里挑 12 条

只挑**能提升可用性、不是纯炫技**的。括号里是库里的分类。

| # | 动效（库条目） | 用在哪 | SwiftUI 落地 | 成本 |
|---|---|---|---|---|
| 1 | **惯性甩卡**（物理手势） | 首页主卡栈左右切卡 | `DragGesture` + 速度预测 + `.spring` | 中 |
| 2 | **弹簧抽屉**（物理手势） | 输入坞上推 → 全屏对话 | `@GestureState` + 阈值吸附 | 中 |
| 3 | **FLIP 共享元素**（形变转场） | 卡片点开详情，连续放大 | `matchedGeometryEffect` + `.navigationTransition`（iOS 18 可选） | 中 |
| 4 | **果冻按压**（微交互） | 所有可点元素 | `.scaleEffect(pressed ? .96 : 1)` + `.sensoryFeedback(.impact)` | 低 |
| 5 | **点击波纹**（微交互） | 快捷图标、Tab | `Circle()` 遮罩扩散 + `.mask` | 低 |
| 6 | **数字翻滚**（文字排版） | 倒计时、步数、完成率 | `contentTransition(.numericText())` + `withAnimation` | 低 |
| 7 | **逐行顶上来**（入场揭示） | 资讯/待办首屏 | `LazyVStack` + `insert` 动画 + `delay(index * 0.04)` | 低 |
| 8 | **骨架流光**（加载进度） | 资讯加载、股票加载 | 渐变 `mask` + 无限 `linear` 动画（尊重 reduceMotion） | 低 |
| 9 | **描边生长**（加载进度） | 待办完成率圆环 | `Circle().trim(from:0,to:progress)` + `.spring` | 低 |
| 10 | **长按进度环**（微交互） | 「完成待办」防误触 | `LongPressGesture` 0.45s 进度环 + 完成后 `sensoryFeedback(.success)` | 低 |
| 11 | **圆形展开**（形变转场） | 切 Tab 时背景过渡 | `Circle` 从点击点 `scale` 到全屏 + `.clipShape` | 中 |
| 12 | **光晕呼吸**（氛围背景） | 背景两团光斑 | `TimelineView(.animation)` 低频 sin，或 CSS 式 `repeatForever` 6s | 低 |

## 3. 明确不采用（省电 + 情绪不对）

| 不采用 | 理由 |
|---|---|
| 片元着色器（极光/液态球/水面/万花筒/隧道） | 常驻 GPU，发热耗电；和"安静陪伴"冲突 |
| 画布粒子（烟花/星空/拖尾/雨雪） | 只保留在「玩一下」的物理盒子，不进主流程 |
| 3D 翻转 / 指针视差倾斜 | 信息型界面里的无谓噪音，长用会晕 |
| 故障抖动 / 字符扰乱解码 | 情绪是"赛博吵闹"，不是 Nomi |
| 逐字打字机 | 长回答会拖慢阅读；只保留在语音字幕 |
| 粒子迸发 | 仅"完成待办"允许一次，别处禁止 |
| 百叶窗 / 碎片旋入 / 斜切 | 太舞台化，日常界面显得廉价 |

## 4. 动效令牌（写进代码，不散落）

```swift
enum Motion {
    static let fast   = Animation.spring(response: 0.28, dampingFraction: 0.86)  // 点按、勾选
    static let base   = Animation.spring(response: 0.34, dampingFraction: 0.78)  // 卡片、抽屉
    static let slow   = Animation.spring(response: 0.52, dampingFraction: 0.82)  // 页面级
    static let settle = Animation.easeOut(duration: 0.18)                        // 颜色、透明度
}
```

- 位移一律 ≤ 24pt；单屏同屏动画 ≤ 3 个元素组
- 全部检查 `@Environment(\.accessibilityReduceMotion)`：开启时位移/旋转归零，只留淡入
- 触觉：`sensoryFeedback` —— 成功 `.success`，按压 `.impact(.light)`，错误 `.error`
- 性能预算：首页常驻动画 ≤ 1 个（光晕呼吸）；列表入场只在首次


## 4.5 字号规范（2026-11-15 修订：不允许特别小的字）

### 体检结果

| 位置 | 情况 |
|---|---|
| `nomiScaled` 调用 | 555 处；其中 **201 处**写的是 8–11.5pt，靠兜底才到 11.5 |
| 底部导航标签 | 10.5pt |
| 三屏稿 | 14 个字号 < 12px（9.5 / 10.5 / 11 / 11.5） |

iOS 参考：caption2 = 11、caption1 = 12、footnote = 13、正文 17。
**11.5pt 中文在 iPhone 16 Pro 上偏小**，元信息（"今天 18:00 前""更新于 8 分钟前"）最容易看不清。

### 规范（写死，不许破）

| 角色 | 字号 | 用在哪 |
|---|---|---|
| 大标题 / 大数字 | 30–34 | 首页问候、倒计时 |
| 页面标题 | 24–26 | 「今天值得知道」「待办」 |
| 卡片标题 | 17–20 | 「周会」「交房租」 |
| 正文 | **15–16** | 资讯摘要、对话气泡 |
| 次级文字 | **13–14** | 地点、拖了几天 |
| 元信息 / 标签 | **12.5** | 来源、更新时间、Tab 标签 |
| 绝对下限 | **12.5** | 任何文字都不低于它 |

- 图标可以 15–18，但那是图形，不算文字
- `Font.nomiScaled` 兜底已从 **11.5 → 12.5**（`WhaleStyle.swift`）
- 底部 Tab 标签 10.5 → **12.5**（`RootView.swift`）
- Dynamic Type 仍然生效：下限 12.5，上限保持原逻辑（基础字号 × 1.65，最低 18）
- 允许 12.5 的只有"元信息"一类；正文绝不低于 15

## 5. 新界面结构（信息层级重排）

### ① 对话（主界面）
```
角色 + 「今天 3 件事 · 更新于刚刚」 + 设置
─────────────────────────────
[ 主卡栈 ]  ← 一屏只突出这一张
   09:30–10:00 · 会议室 A      34分（数字翻滚）
   周会
   上周数据还差一页，先补上就够用。
   [ 问它一句 ]  [ 怎么去 ]
   · · ▬  ← 可左右甩
─────────────────────────────
[待办] [值得知道] [音乐] [玩一下]   ← 果冻按压 + 波纹
─────────────────────────────
[ 现在 21° 多云 ]  [ 步数 3,064 / 8000 + 进度条 ]
─────────────────────────────
( 输入坞，上推变全屏对话 )
```
**变化**：把原来并列的"主卡 + 快捷 + 小卡"改成"主卡栈（可甩）→ 快捷 → 小卡"，视线从一处开始。

### ② 今天值得知道
```
角色 + 「今天值得知道 · 中文 · 在 Nomi 内打开」 + 刷新
[全部][新闻][AI][微博][知乎][行情]     ← 选中项胶囊弹簧变形
─────────────────────────────
新闻卡（来源 · 更新于 8 分钟前）
微博卡（榜位）
骨架流光（加载中）
```
**变化**：所有卡片统一"来源 + 更新时间"行；加载有骨架而不是空白；列表逐行入。

### ③ 待办
```
角色 + 「待办 · 今天完成 2 / 5」 + 完成率圆环（描边生长）
─────────────────────────────
今天 / 明天 / 以后 分组
○ 交房租   今天 18:00 前 [到期]   ← 逾期只染日期
○ 回复设计稿意见   拖了 2 天
✓ 给妈妈回电话   刚刚完成          ← 勾选回弹 + 触觉
```
**变化**：顶部加完成率圆环（唯一可以"炫"的数字动画）；勾选有回弹与触觉；完成项保留 1 秒回执。

## 7. 验收标准

- [ ] 首页 5 秒内能说出"现在最该做什么"
- [ ] 任何一个可点元素，按下 60ms 内有视觉反馈，抬手有触觉
- [ ] 甩卡能切换、能回弹，不误触发聊天返回
- [ ] 资讯加载不再出现空白屏
- [ ] 数字变化不倒跳（翻滚方向正确）
- [ ] 任何界面文字不小于 12.5pt；正文不小于 15pt；大字号设置下不截断
- [ ] 打开"减弱动态效果"后，所有动画只剩淡入，无位移
- [ ] 首页常驻动画 ≤ 1 处；连续滚动 60 秒不发热明显
- [ ] 角色、三 Tab、设置入口、音乐来源、资讯中文等仓库不变量不变

## 8. 与仓库不变量对齐

- 角色本体（钛合金/眼睛/表情/眨眼/视线/拖拽/物理）**零改动**，只在外面套容器动画
- 底部仍是三个入口：对话 / 今天值得知道 / 待办；设置仍在右上角
- 音乐仍来自 iPhone「音乐」资料库，不占灵动岛
- 资讯仍为中文、仍在 Nomi 内打开
- 不新增权限
