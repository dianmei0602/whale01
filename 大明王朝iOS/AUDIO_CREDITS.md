# 声音来源与使用说明

## 背景音乐

曲名：松风入卷

性质：为本项目编写的原创古琴风格程序化配乐。旋律采用宫、商、角、徵、羽五声音阶，以稀疏拨弦、长衰减与空间混响模拟古琴气质。它不是历史古琴录音，也不冒充《流水》《平沙落雁》等传统曲目的某一次演奏。

制作方式：浏览器 Web Audio API 实时合成，无第三方录音、无外部音频文件、无网络依赖。

## 朗读

生产路径：讯飞开放平台“在线语音合成（流式版）WebAPI”，由本地 `server.mjs` 在服务端签名并转发音频，浏览器端不接触 `API_KEY` 或 `API_SECRET`。

降级路径：未配置讯飞凭据、离线打开或服务不可用时，明确切换到设备自带的中文语音，并在界面提示“系统朗读”。

当前账号验证：标准在线合成 `wss://tts-api.xfyun.cn/v2/tts` 与讯飞小露 `x4_yezi` 发音人已实际返回 MP3 并在浏览器中播放。

私有超拟人线路 `wss://cbm01.cn-huabei-1.xf-yun.com/v1/private/mcd9m97e6` 可以完成 WebSocket 鉴权，但它的发音人列表不接受 `x4_yezi`，会返回 `10163`。因此 `server.mjs` 在检测到“私有线路 + x4_yezi”时自动使用标准流式接口，`/api/tts/status` 会同时报告请求线路、实际线路和回退原因。若以后改用私有线路支持的 x5/x6/x7 发音人，可删除该自动回退条件。

所有凭据只保存在本地 `.env`，并已加入 `.gitignore`。不要把 `.env` 放进截图、网页源码或公开仓库。

## 真机局域网朗读

本地服务监听 `0.0.0.0:4173`，iOS 包内配置的语音服务地址为 `http://192.168.110.10:4173`。iPhone 与开发电脑需要处于同一 Wi-Fi，且 Windows 防火墙需要允许 Node.js 访问专用网络。IP 地址变化后，需要同步修改 `Info.plist` 的 `DamingTTSServer` 并重新构建。

讯飞官方接口文档：https://www.xfyun.cn/doc/tts/online_tts/API.html

正式发布前需在讯飞控制台确认账号、发音人授权、并发与调用量限制，并遵守讯飞开放平台服务条款。
