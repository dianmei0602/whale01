## 2. 来源（可核验）

- 发布机构：**自然资源部** 标准地图服务，`http://bzdt.ch.mnr.gov.cn/`（本机 HTTPS 证书链异常，HTTP 可正常访问）
- 获取方式（脚本可复现）：
  1. `GET /sbsm/supermap/searchPicture.do?superclass=中国全图&pageSize=12&currentPageNum=1`
     → 2048 条标准地图条目，每条含 `mapNumber`（审图号）、`scale`、`size`、`jpgPath`。
     本次目标：`superclass=中国全图` 下 `mapNumber = GS(2022)4307号` 的条目，`pictureId = 4o28b0625501ad13015501ad2bfc0698`。
  2. `POST /sbsm/supermap/downloadPic.do?pictureId=<id>&picType=jpg`
     → `{"type":1,"message":"https://bzdt-sbsm.obs.cn-north-4.myhuaweicloud.com/prototype/4/....zip!@#<文件名>"}`
     → GET 该 OBS 链接得 zip，内含 **10599 × 6867 / 300 dpi / CMYK** 原始 JPG（9.28 MB）。
  3. 等比缩放到 3200 px 宽、JPEG q82 → `www/assets/standard-map.jpg`（**未裁剪、未改色、未改边界**）。
- 对比：iServer 切片（`tileImage.png?x=&y=&z=`）亦可取图，但清晰度与本链路原图不可比，且拼接无印刷审图号，故未采用。

## 3. 使用限制（依标准地图使用要求）

1. **不得改动地图内容**：不得增删、遮盖、变形或重绘边界与注记；本项目仅整体等比缩放（同一比例缩放不改变内容关系），未裁剪审图号。
2. **完整使用并标注来源**：页面常驻「底图：自然资源部标准地图服务 · 审图号 GS(2022)4307号」；任意截图/分享须保留该标注与整幅图。
3. 不得与其他来源拼接、不得作为测绘成果使用。
4. 官方发布更新版时，应整体替换为对应新版并同步更新页面文案与本文件。
5. 交互层（战役点位、聚合气泡）是叠加图层，**不是地图内容本身**，仅作阅读辅助，不得据此量测。

## 4. 「经纬度 → 像素」标定

### 4.1 方法（2.1 更新）

1. **初值迁移**：新旧两版均为 1:740万 / 300dpi，故「km/px」与投影一致，两图之间只差平移。用**相位相关**（边缘图 FFT）求得平移量 **dx = +610.2 px, dy = −3.1 px**（新图像素 = 旧图像素 + 该平移），把 2.0 的旧标定直接迁移过来作初值。
2. **图面控制点**：在初值位置 ±190 px 的全分辨率窗口内检测城市符号（深色/红色连通域 + 圆形度 + 尺寸过滤），**34/34 个省会/特别行政区全部命中**。
3. **鲁棒拟合**：RANSAC（6 点子集 × 8000 次）取 **22 个内点**，最小二乘拟合二次多项式 `(lng,lat) → (px,py)`；迭代收紧阈值至稳定。
4. **验证**：留一交叉验证 + 逐点裁剪目视（`artifacts/m6-map/` 内截图）。

### 4.2 精度

| 指标 | 2.1 有邻国版（当前） | 2.0 无邻国版（旧） |
| --- | --- | --- |
| 控制点 | 34 候选 → **22 内点** | 34 候选 → 20 内点 |
| 内点残差均值 | **3.69 km** | 4.26 km |
| 内点残差最大 | ≈ 9.5 px ≈ 6.0 km | ≈ 11.3 px ≈ 7.1 km |
| 留一交叉验证 | **5.68 km** | 6.05 km |
| 换算 | 原图 1 px ≈ 0.6265 km；资产 1 px ≈ 2.07 km | 资产 1 px ≈ 1.85 km |

> 官方发布的是纸质标准地图，自然资源部未随图提供地理配准参数（iServer 服务 `prjCoordSys = PCS_NON_EARTH`，`bounds` 为自定义平面坐标；`queryResults` 返回 400，取不到省界坐标）。
> 本标定为「图面城市符号控制点 + 二次多项式」的经验拟合，**属展示级精度**（手机全图缩放下 3–6 km ≈ 2–3 px），不作量测使用。
> 若需优于 2 km：需官方图廓点（四角经纬度）或出版方配准参数，或改用带 CRS 的 WMS/WMTS（本站 `map-china400/wms111`）。

### 4.3 参数（可直接复用，资产像素空间）

图片像素：`width=3200, height=2073`；归一化 `u=(lng-105)/30`，`v=(lat-35)/20`；基函数 `[1, u, v, u², uv, v²]`。

```
cx = [1560.673508, 1278.426529, 66.242249, -4.160836, -352.341108, 18.558034]
cy = [1089.072808, 45.986769, -1073.996724, -176.936858, 2.982154, -1.120347]

px = cx0 + cx1*u + cx2*v + cx3*u*u + cx4*u*v + cx5*v*v
py = cy0 + cy1*u + cy2*v + cy3*u*u + cy4*u*v + cy5*v*v
```

- 输入经纬度范围（120 场实际取值）：**lng 71.4–133.9，lat 18.1–53.6**
- 对应资产像素范围：**x ≈ 300–3060，y ≈ 300–2000**（全部在图幅内）
- 同一组系数内联在 `www/js/map.js` 的 `STD` 常量（`cx` / `cy` / `width` / `height`），换图只改这一处与本文件
- 完整 34 个控制点像素坐标与内点标记：`artifacts/m6-map/calibration-params.json`

## 5. 交互与兜底

- **双模式兜底**：`standard-map.jpg` 加载失败时，`map.js` 自动回退 `china-geo.js` 的示意矢量轮廓，并在提示区显示「已回退示意轮廓」，120 点仍按经纬度绘制。
- **境外标识**：`inChinaLL()` 以经纬度判定（不再依赖底图投影），境外点保留「境外示意」图例与摘要卡标记。
- **交互保留**：120 点落位、聚合、缩放/拖动、时期与类型筛选、摘要卡直达详情均不变。
- **换图流程**：按第 2 节重新取图 → 等比缩放 → 旧图改名保留 → 用 §4.1 方法重标定（相位相关迁移 + 城市符号 RANSAC）→ 更新 `map.js` 的 `STD` 与页面文案 → 更新本文件。
